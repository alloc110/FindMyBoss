Hệ thống sẽ hiển thị JD chi tiết, hỗ trợ Gemini tối ưu hóa CV và biên dịch file PDF trực tiếp.

Cài đặt Hệ thống & Tùy chọn (Settings)

Hỗ trợ đa nhà cung cấp. Bạn có thể dùng Gemini miễn phí, ChatGPT, Claude hoặc mô hình nguồn mở cục bộ.
Chọn mô hình phân tích JD, trích xuất kỹ năng và tối ưu hóa nội dung CV chuẩn ATS.
Địa chỉ endpoint tương thích OpenAI API (DeepSeek: https://api.deepseek.com/v1, Ollama: http://localhost:11434/v1).
Lấy API Key miễn phí tại Google AI Studio (aistudio.google.com). Nếu để trống, hệ thống sẽ chạy ở Chế độ Mô phỏng Thông minh.
